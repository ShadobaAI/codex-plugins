# ShadobaAI — плагины для Codex

Магазин плагинов ShadobaAI для Codex: навыки, инструменты и интеграции.

## Установка

1. Открой настольное приложение Codex.
2. Перейди в **Плагины (Plugins)** → **Добавить (Add)** → **Добавить магазин (Add Marketplace)** → **Из репозитория (Add from a repository)**.
3. Скопируй адрес этого репозитория из адресной строки GitHub, вставь его в окно добавления магазина и нажми **Синхронизировать (Sync)**.
4. Открой добавленный магазин, выбери нужный плагин и нажми **Установить (Install)**. Убедись, что плагин включён.
5. Начни новый чат и попроси Codex использовать установленный плагин.

Дополнительные программы и разрешения зависят от выбранного плагина. Проверь его инструкцию перед первым использованием. Подробнее об установке — в [документации Codex](https://learn.chatgpt.com/docs/plugins).

## Плагины

| Плагин | Назначение | Инструкция и исходники |
| --- | --- | --- |
| **Накидка** (`md-design`) | Интерактивные прототипы форм 1С по тексту, скриншоту или XML | [ShadobaAI/md_design](https://github.com/ShadobaAI/md_design) |

Пример запроса после установки Накидки:

```text
Используй Накидку. Создай форму поступления: номер, дата,
контрагент и таблица товаров. Открой её во встроенном браузере.
```

## Обновление и удаление

Чтобы обновить магазины, попроси Codex выполнить:

```text
codex plugin marketplace upgrade
```

Команда обновляет все подключённые Git-магазины. После успешного обновления перезапусти приложение и начни новый чат. [Справочник команд](https://learn.chatgpt.com/docs/cli/reference#codex-plugin-marketplace).

Для удаления открой **Плагины**, выбери установленный плагин и нажми **Удалить (Uninstall)**.

## Для разработчика

Храни исходники и инструкции каждого плагина в его собственном репозитории. Для добавления плагина в магазин:

1. Собери и проверь готовый пакет в репозитории исходников.
2. Размести пакет в `plugins/<имя-плагина>/`.
3. Добавь запись в массив `plugins` файла [.agents/plugins/marketplace.json](.agents/plugins/marketplace.json). Для локального пакета укажи `source.source = "local"` и `source.path = "./plugins/<имя-плагина>"`; путь считается от корня магазина.
4. Добавь плагин в таблицу выше со ссылкой на его инструкцию и исходники.
5. Проверь установку через Codex перед публикацией.

При выпуске новой версии обновляй пакет и запись своего плагина, сохраняя остальные плагины и настройки магазина. Условия использования и лицензия указаны в каждом пакете.

Формат каталога и подключение локального магазина описаны в [документации OpenAI](https://developers.openai.com/plugins/build/plugins#marketplace-metadata).
