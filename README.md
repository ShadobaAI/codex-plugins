# Накидка

Плагин Codex для создания интерактивных прототипов форм 1С по тексту, скриншоту или XML.

## Установка

Нужны Codex и Node.js 22+.

```powershell
codex plugin marketplace add ShadobaAI/md_design-mkt
codex plugin add md-design@shadobaai-md-design
```

После установки начните новый чат и попросите Codex создать прототип формы.

[Исходники и документация](https://github.com/ShadobaAI/md_design). Пакет и каталог marketplace обновляются автоматически через CI.
